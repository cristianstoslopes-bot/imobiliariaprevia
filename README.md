# Prévia · Gestora Imobiliária Sandra Barbosa

Prévia visual (mockup navegável) da página inicial do site da Gestora Imobiliária Sandra Barbosa, CRECI 153963-F.

- `index.html`: página única, sem build. Abas "Prévia do site" e "Guia de design" (`#guia`).
- `img/`: fotos ilustrativas da prévia.

Fotos, imóveis, preços, números e depoimentos são exemplos. Trocar pelos dados reais antes de publicar o site definitivo.

Deploy: Vercel, projeto estático (sem comando de build), publicado a cada push na `main`.
